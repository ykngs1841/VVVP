# Virtual Vehicle Verification Platform

## 프로젝트 소개

사용자가 입력한 차량상태 기반으로 차량 동작을 검증하는 가상 차량 검증 시뮬레이션

## 프로젝트 목표

- 객체지향 기반 자동차 소프트웨어 설계
- ECU 제어 로직 모델링
- 차량 시동 및 종료 로직 구현
- 사용자 입력 기반 시뮬레이션 구현
- 차량 상태 검증(PASS / FAIL)

##핵심 기능

- 사용자 차량 상태 입력
- ECU 제어 로직 판단
- Engine Start / Stop
- Battery Condition Check
- Gear Validation
- Dashboard 상태 변경
- Verification Result 출력
- Logger 기록      


## 동작 원리

1. 사용자 입력
2. ECU 조건 확인
3. 차량 상태 변경
4. 실행결과 검증
